아두이노 신호등 실습 정리

Arduino UNO · 버튼으로 작동하는 신호등 · 2026년 10월 23일

초록불 유지 → 버튼 누름 → 노란불 3초 → 빨간불 10초 → 초록불 유지

1. 배선 정보

부품 / 접점아두이노 연결
버튼 접점 한쪽디지털 8번
버튼의 다른 접점GND
신호등 모듈 R — 빨강디지털 9번
신호등 모듈 Y — 노랑디지털 10번
신호등 모듈 G — 초록디지털 11번
신호등 모듈 GNDGND

저항 내장형 R·Y·G·GND 신호등 모듈 기준입니다. G는 초록불, GND는 접지입니다. 배선을 변경할 때는 USB를 분리하세요.

버튼은 INPUT_PULLUP을 사용합니다. 버튼을 떼면 HIGH(1), 누르면 LOW(0)가 되어야 합니다. 4핀 버튼은 눌렀을 때만 연결되는 두 접점을 사용하고, 브레드보드에서 두 접점이 항상 이어지지 않도록 꽂습니다.

2. 동작

전원을 켜면 초록불만 켜집니다. 버튼을 누르면 초록불이 꺼지고 노란불이 3초 동안 켜집니다. 이어서 노란불이 꺼지고 빨간불이 10초 동안 켜집니다. 그 뒤 빨간불이 꺼지고 초록불이 다음 버튼 입력까지 유지됩니다.

노란불·빨간불 동안의 버튼 입력은 무시합니다. 버튼을 계속 누르고 있어도 반복 실행되지 않습니다. 부저와 음악 코드는 포함하지 않았습니다.

3. 전체 코드

const byte BUTTON = 8;
const byte RED = 9;
const byte YELLOW = 10;
const byte GREEN = 11;

// 0: 초록불, 1: 노란불, 2: 빨간불
byte lightState = 0;
unsigned long lightStarted = 0;

int lastReading = HIGH;
int stableButton = HIGH;
unsigned long buttonChanged = 0;
bool buttonReady = false;

void setLight(byte pin) {
  digitalWrite(RED, LOW);
  digitalWrite(YELLOW, LOW);
  digitalWrite(GREEN, LOW);
  digitalWrite(pin, HIGH);
}

void setup() {
  pinMode(BUTTON, INPUT_PULLUP);
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);

  setLight(GREEN);

  lastReading = digitalRead(BUTTON);
  stableButton = lastReading;
  buttonChanged = millis();
}

void loop() {
  unsigned long now = millis();
  int reading = digitalRead(BUTTON);

  // 버튼 접점의 흔들림 제거
  if (reading != lastReading) {
    lastReading = reading;
    buttonChanged = now;
  }

  if (now - buttonChanged >= 40) {
    // 버튼을 뗀 뒤에만 다음 누름을 받음
    if (reading == HIGH) {
      buttonReady = true;
    }

    if (reading != stableButton) {
      stableButton = reading;

      if (stableButton == LOW && buttonReady) {
        buttonReady = false;

        // 초록불일 때만 신호등 순서 시작
        if (lightState == 0) {
          setLight(YELLOW);
          lightState = 1;
          lightStarted = now;
        }
      }
    }
  }

  // 노란불 3초 후 빨간불
  if (lightState == 1 &&
      now - lightStarted >= 3000UL) {
    setLight(RED);
    lightState = 2;
    lightStarted = now;
  }
  // 빨간불 10초 후 초록불 유지
  else if (lightState == 2 &&
           now - lightStarted >= 10000UL) {
    setLight(GREEN);
    lightState = 0;
  }
}

Arduino IDE의 기존 코드를 모두 지우고 위 코드만 붙여넣은 뒤, → 업로드 버튼을 누르세요. 업로드가 완료되면 자동으로 실행됩니다.
